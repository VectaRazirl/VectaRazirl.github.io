プライバシーポリシー

本方針は、個人用ツールStockAnalysis-IR-DailyによるGoogleユーザーデータの取扱いを説明します。

取得・利用するデータ

対象Google Sheetsから企業コード・企業名・最終確認日を読み取り、IR資料の取得対象と必要期間を決定します。Google Drive内のアプリが利用を許可された保存先・既存ファイルの情報と内容を確認し、IR資料の重複保存防止、保存結果の照合、結果JSON・PDFの保存に利用します。

保存・処理先

取得処理はGitHub Actionsで実行します。処理用の認証情報はGitHub ActionsのSecretで管理し、処理時にGoogle APIへ使用します。企業コード・確認期間・処理結果などが実行ログに記録される場合があります。取得結果とPDFはGoogle Driveに保存します。公開IR情報の取得時には、取得元へ企業コード等の検索条件を送信します。

利用範囲と公開

Googleユーザーデータは本人のIR取得・保存・検証の目的に限って利用します。販売、広告配信、一般利用者への公開の目的では利用しません。この説明サイトに台帳、認証情報、取得結果を掲載しません。処理の実行・保存にはGoogleとGitHubのサービスを利用します。

保存期間・削除・アクセス取消

取得資料・結果は本人の確認と記録のために保持し、不要になったものは本人が管理する保存先で削除します。一律の自動削除期間は設定していません。Googleアカウントの接続管理からアプリへのアクセスを取り消せます。アクセス取消だけでは既に保存された資料や実行ログは削除されません。認証情報の廃止時はGitHub Secretも別途管理します。

Google APIデータの利用

Google APIから受領した情報の使用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。
